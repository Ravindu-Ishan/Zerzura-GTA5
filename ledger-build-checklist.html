World & vehicles

0 / 5 · 0%

Since this is a private friends-only server, you're free to reskin and rebrand without worrying about licensing — that opens up the "replace" approach, which is far less work than it sounds.

Decide: replace vs. add-on vehiclesDecision

Replace packs swap the model on the existing GTA vehicle slot — every shop entry, spawn command, and script reference keeps working with zero code changes, at the cost of losing the original vehicle entirely. Add-on packs stream in alongside the originals under new names, which is more flexible but means re-pointing every vehicle shop, garage, and NPC spawn list yourself. For "replace the existing ones with realistic counterparts," replace packs are almost always the right call.

Source realistic replacement models by classverify current name

Work class-by-class against your existing vehicle shop categories (sedans, sports, SUVs, muscle, trucks — and the semi/trailer combo you'll need for Phase 5's trucking job) rather than one giant undifferentiated pack, so nothing gets missed.

Tune handling.meta for the new modelsCustom pass

A dropped-in real-badged model with the stock GTA handling underneath still drives like the original car. Worth a deliberate pass per class rather than accepting pack defaults.

Add interior MLOs (housing, shops, hangouts)verify current name

Prioritize by what Phase 4 needs first: the hotel room / cheap apartment interiors for the bottom of the housing ladder, then business-purchase interiors, then pure social hangout spots.

Visual/graphics pass (timecycle, weather, vibrant streaming assets)verify current name

Do this after the vehicle and interior passes, not before — lighting and weather mods are easiest to judge once the world actually has your content in it.

Benny's Original Motor Works — direct answer: the building itself (Strawberry, on the map) exists in FiveM because it's part of the base GTA V map, same as it is in singleplayer. But the special customization menu and functional interior that Benny's has in GTA Online was added by the Lowriders DLC as its own bespoke system — it is not wired up out of the box in qbox, QBCore, or vanilla FiveM. To get a working Benny's, you need a dedicated script (sometimes bundled with an MLO, sometimes standalone) that opens the doors, adds the interaction points, and hooks the unique upgrade menu into your vehicle-mod system. I couldn't run a live search this session to hand you a specific current resource name with confidence — search the Cfx.re forum or Tebex for "Benny's" scripts before you build one from scratch, since this is a well-worn request in the FiveM scene and something almost certainly exists.
03

Admin placement tool

0 / 8 · 0%

Your own project: an in-game editor so you can select a prop, ped, marker, or zone and reposition/rotate/resize it without fighting AI-generated coordinate math. Worth building early — you'll use it for every interior, job location, and marker in every phase after this one.

Entity picker (raycast under crosshair)Custom build

Client-side raycast from the camera to find the nearest object, ped, or vehicle under the cursor, using natives like GetEntityPlayerIsFreeAimingAt or a manual ray/hit test against GetClosestObjectOfType results. This is the entry point for everything else.

Category filter: prop / ped / marker / zoneCustom build

Markers and zones (job blips, trigger areas) aren't real entities, so they need their own selectable representation — a small always-visible gizmo prop, or highlighted when the tool is active, that maps back to a marker ID in your config.

Move gizmo (translate on X/Y/Z, with a nudge mode)Custom build

Keybind-driven nudge (arrow keys + modifier for axis, small/large step toggle) is far faster to build and use reliably than a mouse-drag 3D gizmo — you can add drag later once the keybind version works.

Rotate control (heading + full pitch/roll if needed)Custom build

SetEntityRotation with a keybind or scroll-wheel step. Most props only need heading; save pitch/roll control for the cases that actually need it.

Resize / scale controlCustom build

Native scale support is limited for many prop types — you may end up swapping between a few pre-scaled model variants rather than true runtime scaling for some objects. Worth confirming per prop type before assuming free scaling works everywhere.

NUI panel: numeric fine-tune + entity listCustom build

A small HTML/JS overlay showing exact coordinates/rotation and a searchable list of placed objects — keybind-only editing gets tedious once you have more than a handful of placed items.

Save/load to database (not just runtime memory)Custom build

Every placed prop, marker, and NPC needs to persist across server restarts — write to a table on save, and spawn everything from that table on resource start.

Ace-permission gate the whole toolCustom build

Restrict activation to your admin ace group from day one — easy to forget until a friend finds the command by accident.

Housing & business ladder

The bottom-to-top money sink your blueprint doc's economy section depends on: start broke, rent a room, work up to ownership. This is the system that gives early cash somewhere to go.

Starting cash + starter job wired to bankConfig

Small enough that a hotel room is a real decision, not a rounding error — tune against whatever the cheapest room costs per night.

Rentable hotel room tier (nightly/weekly rent, no ownership)verify current name

The floor of the housing ladder — needs basic storage but no furnishing, and should be unrentable-if-unpaid rather than instant eviction, to keep it low-stakes.

Apartment tier (owned/leased, storage + furnishing)verify current name

First real ownership rung. Confirm the housing script supports tiered rent/mortgage rather than a flat one-size price — that's what makes the climb feel like a climb.

Business purchase systemverify current name

Needs an ownership record, not just a physical shop — whoever owns it should be able to lock others out, sell it, or hand it off.

Business customization/config (like GTAO's business upgrades)Custom build

What the business "comes with" and what you can pay to upgrade — staff slots, production speed, storage capacity. This is closer to Phase 3's admin tool territory (placing shelving, staff NPCs, decor) than an off-the-shelf script.

Passive income tick for owned businessesCustom build

A capped trickle that accrues even offline, per your blueprint doc's design (never out-earning active play) — a scheduled server-side job that pays out per owned business on an interval.

Trucking career

0 / 7 · 0%

Your fully-specced job: deliver goods, level up, unlock longer and riskier routes. Legal freight is the safe income floor; illegal freight is the high-risk, high-reward ceiling.

Base delivery loop: pick up, haul, drop off, get paidCustom build

Start with one truck, one trailer type, short routes — get the core loop solid before adding the leveling and risk layers on top of it.

Job XP/level system tied to completed deliveriesCustom build

Store level + XP per character in its own DB table; gate everything below behind level thresholds rather than unlocking it all at once.

Cargo condition tracking (damage reduces payout)Custom build

Tie a "cargo health" value to trailer damage events or hard driving — drops in value on impact, final payout scales off remaining condition at drop-off.

Long-haul tier: longer routes, higher base pay, unlocked by levelCustom build

Legal but slower and further — the "grind" rung that rewards patience without any risk layer yet.

Illegal freight tier: contraband loads, higher pay ceilingCustom build

Same delivery loop, different cargo flag — contraband runs pay more but should trip your dispatch/police-alert system per your blueprint's heat mechanics.

Police/gang interception risk on illegal runsCustom build

Random or dispatch-triggered ambush points on contraband routes — ties directly into the same territory/gang-rep systems from Phase 6 and your blueprint's criminal ladder, so build it to read from the same rep values rather than a standalone risk roll.

Trailer/cargo variety (flatbed, tanker, reefer, etc.)verify current name

Different trailer types can gate different cargo categories (hazardous, refrigerated, oversized) as another progression axis within the job itself.

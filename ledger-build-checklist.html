02

World & vehicles

Since this is a private friends-only server, you're free to reskin and rebrand without worrying about licensing — that opens up the "replace" approach, which is far less work than it sounds.

Decision

Replace packs swap the model on the existing GTA vehicle slot — every shop entry, spawn command, and script reference kicks on working with zero code changes, at the cost of losing the original vehicle entirely. Add-on packs stream in alongside the originals under new names, which is more flexible but means re-pointing every vehicle shop, garage, and NPC spawn list yourself. For "replace the existing ones with realistic counterparts," replace packs are almost always the right call.

verify current name

Work class-by-class against your existing vehicle shop categories (sedans, sports, SUVs, muscle, trucks — and the semi/trailer combo you'll need for Phase 5's trucking job) rather than one giant undifferentiated pack, so nothing gets missed.

Custom pass

Benny's Original Motor Works — direct answer: the building itself (Strawberry, on the map) exists in FiveM because it's part of the base GTA V map, same as it is in singleplayer. But the special customization menu and functional interior that Benny's has in GTA Online was added by the Lowriders DLC as its own bespoke system — it is not wired up out of the box in qbox, QBCore, or vanilla FiveM. To get a working Benny's, you need a dedicated script (sometimes bundled with an MLO, sometimes standalone) that opens the doors, adds the interaction points, and hooks the unique upgrade menu into your vehicle-mod system. I couldn't run a live search this session to hand you a specific current resource name with confidence — search the Cfx.re forum or Tebex for "Benny's" scripts before you build one from scratch, since this is a well-worn request in the FiveM scene and something almost certainly exists.
03

Admin placement tool

Your own project: an in-game editor so you can select a prop, ped, marker, or zone and reposition/rotate/resize it without fighting AI-generated coordinate math. Worth building early — you'll use it for every interior, job location, and marker in every phase after this one.

Custom build

Client-side raycast from the camera to find the nearest object, ped, or vehicle under the cursor, using natives like GetEntityPlayerIsFreeAimingAt or a manual ray/hit test against GetClosestObjectOfType results. This is the entry point for everything else.

Custom build

Markers and zones (job blips, trigger areas) aren't real entities, so they need their own selectable representation — a small always-visible gizmo prop, or highlighted when the tool is active, that maps back to a marker ID in your config.

Custom build

Keybind-driven nudge (arrow keys + modifier for axis, small/large step toggle) is far faster to build and use reliably than a mouse-drag 3D gizmo — you can add drag later once the keybind version works.

Custom build

SetEntityRotation with a keybind or scroll-wheel step. Most props only need heading; save pitch/roll control for the cases that actually need it.

Custom build

Native scale support is limited for many prop types — you may end up swapping between a few pre-scaled model variants rather than true runtime scaling for some objects. Worth confirming per prop type before assuming free scaling works everywhere.

Custom build

A small HTML/JS overlay showing exact coordinates/rotation and a searchable list of placed objects — keybind-only editing gets tedious once you have more than a handful of placed items.

Custom build

Every placed prop, marker, and NPC needs to persist across server restarts — write to a table on save, and spawn everything from that table on resource start.

Custom build
